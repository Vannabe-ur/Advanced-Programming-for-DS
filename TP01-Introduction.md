## Python Naming code convention

In Python, code naming conventions are defined by the official style guide, PEP 8 – Style Guide for Python Code. Following these standards ensures your code is clean, professional, and easy for other developers to read.

The definitions for Python elements include:

- **Function:** Reusable code block performing a specific task.

- **Variable:** Named container storing a data value.

- **Class:** Structural blueprint for creating objects.

- **Method:** Function belonging inside a class.

- **Constant:** Variable holding an unchangeable value.

- **Module:** Single file containing Python code.

- **Package:** Directory containing multiple related source files, modules, or components grouped together to share code and manage namespaces.
